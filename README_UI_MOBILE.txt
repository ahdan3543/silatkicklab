Silat Motion - Mobile UI refinement

Perubahan utama:
- Halaman analisis mobile dibuat lebih clean dan konsisten dengan merah UPI.
- Panel hasil tidak lagi memakai gradient hijau/merah yang kuat; menggunakan kartu putih dengan aksen maroon.
- Kontrol Video, 3D Lab, 2D, slow motion, Start/Impak/Kembali dibuat satu bahasa warna.
- Label fase dibuat singkat agar tidak memenuhi layar.
- Kontrol pemutar video tetap lengkap: play, frame step, slow motion, jump to phase, FPS, fullscreen.
- Target dan Kalibrasi tetap tersedia.
- Koreksi titik fase tetap tersedia.
- Layout tetap responsif dan tidak menghilangkan fungsi analisis.
