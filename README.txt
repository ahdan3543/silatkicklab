PERUBAHAN FONT SILAT MOTION

File yang diubah:
- src/index.css
- tailwind.config.js

Perubahan:
- Font utama menjadi Inter (fallback Segoe UI/Arial).
- Heading dibuat lebih rapi dan tidak terlalu berat.
- Tipografi dioptimalkan agar lebih mudah dibaca saat presentasi.

Cara memasang:
1. Extract ZIP ini.
2. Copy folder/file di dalamnya ke folder project Silat Motion.
3. Replace file lama ketika diminta.
4. Jalankan: npm run dev

Catatan: Inter dimuat dari Google Fonts saat internet tersedia; jika tidak tersedia,
aplikasi otomatis memakai Segoe UI/Arial.
